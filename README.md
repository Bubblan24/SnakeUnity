# Snake-Unity

A classic Snake game built with Unity and C#.

## Overview

This project recreates the classic Snake arcade game. Control the snake, collect food, and grow longer while avoiding collisions.

## Features

- Snake movement
- Food collection
- Increasing snake length
- Collision detection
- Score tracking
- Game over conditions

## Built With

- **Engine:** Unity
- **Language:** C#
- **Version Control:** Git and GitHub

## Getting Started

1. Clone or download this repository.
2. Open Unity Hub.
3. Select **Add Project from Disk** and choose the project folder.
4. Open the project using a compatible Unity version.
5. Open the main scene and press **Play**.

## Project Structure

- `Assets/` — Game assets and resources
- `Packages/` — Unity package dependencies
- `ProjectSettings/` — Unity project configuration
